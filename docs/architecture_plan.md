# 简易期货交易训练平台方案设计

## 目标与约束
- **目标**：构建一套面向个人学习的期货行情回放与模拟交易系统，强调功能可用与实现简单，支持用户按需选择期货品种与日期区间开展训练。
- **平台定位**：桌面浏览器访问的单机应用，前端使用 Vue，后端基于 Flask，行情数据来源于 AkShare。
- **约束条件**：
  - 关注实用性与开发效率，优先选择成熟开源库。
  - 仅需支持历史行情回放，不考虑实时行情接入。
  - 支持离线回放本地缓存的历史数据，减少对外网依赖。
  - 系统仅供个人使用，不设计用户或权限体系。
  - 交易逻辑以教学演示为主，简化风控与账户管理。

## 整体架构
```
+------------------------------+
|           前端 Vue           |
|  - 行情/订单面板            |
|  - 回放控制（播放/暂停）    |
|  - 策略及账户状态展示       |
+--------------+---------------+
               |
               | REST/WebSocket
               v
+------------------------------+
|          Flask 后端          |
|  - 行情管理器                |
|  - 回放调度器                |
|  - 模拟撮合 & 账户管理      |
|  - 数据缓存（SQLite）        |
+--------------+---------------+
               |
               | AkShare API / 本地数据
               v
+------------------------------+
|        数据源与存储          |
|  - 历史行情拉取（AkShare）   |
|  - 本地缓存与回放数据集     |
+------------------------------+
```

## 模块划分
### 1. 数据层
- **数据拉取服务**：使用 AkShare 获取主流期货品种的分钟级或 Tick 级历史数据，支持命令行脚本定期更新。
- **数据缓存**：
  - 直接使用 SQLite 作为本地数据仓库，集中管理合约与时间区间索引；
  - 借助 Pandas/SQLAlchemy 完成批量导入与查询。
- **回放数据集管理**：提供接口供前端选择合约、时间区间，后端从 SQLite 中抽取并预处理成回放序列。
- **指标预处理**：基于 Pandas 在后端计算 K 线、布林带（BOLL）、成交量及常用量价指标，随行情数据一并缓存或按需生成。

### 2. 行情回放模块
- **回放调度器**：按照用户设定的速度、步长发送行情快照。
- **推送机制**：
  - 简化方案：使用长轮询/REST 轮询；
  - 进阶方案：基于 Flask-SocketIO 实现 WebSocket 实时推送。
- **回放控制 API**：启动、暂停、快进、跳转指定时间点。

### 3. 模拟交易模块
- **订单管理**：支持限价/市价单、撤单操作。
- **撮合逻辑**：
  - 根据回放行情撮合；
  - 简化成交规则（如完全成交或按价位撮合）。
- **账户管理**：跟踪持仓、可用资金、盈亏、保证金占用。
- **策略接口（可选）**：预留 REST/Webhook 供未来接入简单策略。

### 4. 后端 API 设计
- `/api/contracts`：获取可回放的合约列表及可用时间区间。
- `/api/playback/start`：参数包括合约、起止时间、回放速度。
- `/api/playback/pause`、`/api/playback/resume`、`/api/playback/seek`。
- `/api/market/next`：轮询模式下获取下一条行情。
- `/api/orders`：下单、撤单、查询订单列表。
- `/api/account`：查询账户信息。

### 5. 前端功能
- **页面布局**：
  - 左侧：K 线/分时图（含成交量副图与 BOLL 指标）、盘口数据。
  - 右侧：订单输入、持仓/资金显示、回放控制面板。
- **状态管理**：采用 Pinia 或 Vuex 管理行情、订单、账户状态。
- **组件划分**：
  - `MarketChart`：基于 ECharts 展示 K 线主图、BOLL 指标与成交量副图，可切换量价指标；
  - `OrderPanel`：订单输入、下单按钮；
  - `PlaybackControl`：播放、暂停、速度调节；
  - `AccountSummary`：持仓与权益。
- **网络层**：使用 Axios 与后端交互，长轮询或 WebSocket 接收行情推送。

## 开发里程碑
1. **基础骨架**
   - 初始化 Flask + Vue 工程结构，配置依赖。
   - 实现最小化的回放 REST API 与前端展示界面。
2. **行情回放 MVP**
   - 完成历史数据拉取脚本（AkShare）。
   - 实现回放调度器，前端可以播放/暂停查看行情。
3. **模拟交易核心**
   - 实现下单、撮合、账户管理；
   - 前端提供订单操作与账户展示。
4. **增强体验**
   - 支持回放速度调节、时间跳转；
   - 引入 WebSocket 推送、增加多合约支持。
5. **测试与文档**
   - 单元测试：数据处理、交易逻辑。
   - 使用说明：环境搭建、运行步骤。

## 技术选型与依赖
- **后端**：Flask、Flask-RESTful/Flask-SocketIO、Pandas、AkShare、SQLite（通过 SQLAlchemy 访问）。
- **前端**：Vue 3、Vite、Pinia、ECharts（行情图表）。
- **工具链**：Poetry 或 pip + requirements.txt；前端使用 pnpm/yarn。

## 风险与缓解
- **AkShare 接口变动**：使用版本锁定与本地缓存，避免接口变动影响。
- **行情数据体量大**：优先选择分钟级数据，提供合约与时间区间限制。
- **性能瓶颈**：采用批量预加载数据与增量推送，必要时优化为异步处理。

## 后续扩展方向
